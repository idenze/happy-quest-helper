Appearance

Six colours, the logo, the content width, the menu order and the footer. Everything here writes CSS custom properties the whole public site reads.

Colours

Each one is stored as oklch(). The colour picker writes hex; the server converts. Leave a field empty to fall back to the built-in value.

Contrast is checked when you save

If text and page fall below 4.5:1 the save is refused and the old palette stays. Nothing goes live half-broken.

Identity and measure

SVG or PNG. Current: ozituma-mark.svg. With none, the site sets the name in Libre Baskerville.
Any CSS length. Pages are built to hold at 56rem and at 90rem alike.
